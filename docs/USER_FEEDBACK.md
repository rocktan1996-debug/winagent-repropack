# Safe first-run feedback

We welcome **real, voluntary feedback** from developers testing the [public v0.1.0rc2 pre-release](https://github.com/rocktan1996-debug/winagent-repropack/releases/tag/v0.1.0rc2).

Start with `examples/synthetic.log` using the [Chinese quickstart](QUICKSTART_ZH.md). No real client log or Codex account is needed to try the software. The project does not collect analytics or automatically upload reports.

When reporting your experience, share:
- Operating system and Python version (without unique machine identifiers)
- Release tested and whether installation and the synthetic example succeeded
- A specific confusing step, problem, or useful aspect of the generated issue draft
- A minimal **fabricated** reproduction for bugs

**Never post real logs, Doctor files, access tokens, email addresses, home paths, or unreviewed generated reports.** For vulnerabilities use [private vulnerability reporting](../SECURITY.md), not public Issues.

Feedback and suggestions are not proof of adoption until independent contributors actually submit them. We do not promise incentives or inflate usage counts.
